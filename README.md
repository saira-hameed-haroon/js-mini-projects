# JavaScript Mini Projects Portfolio

This repository contains **11 JavaScript mini projects** built as part of my web development learning journey.  
Projects are **numbered in the order they were created**, showing the progression of my skills from basic to more interactive apps.

---

## Projects

1. **01-counter-app** – A simple counter with increment and decrement buttons. ✅  
2. **02-theme-changer** – Toggle between light and dark themes. 🌙  
3. **03-background-color-changer** – Change the background color and display the color code. 🎨  
4. **04-show-hide-password** – Toggle password visibility on input fields. 🔒  
5. **05-image-gallery** – Interactive image gallery with clickable thumbnails. 🖼️  
6. **06-form-validation** – Basic form validation using JavaScript. 📝  
7. **07-search-filter** – Real-time search filter for lists. 🔍  
8. **08-countdown-timer** – Countdown timer with user input. ⏰  
9. **09-calculator** – Basic calculator performing arithmetic operations. ➕➖✖️➗  
10. **10-todo-list** – To-do list with drag-and-drop functionality. ✅   
11. **11-weather-app** – Weather app using API to fetch real-time data. 🌐 ✅

---

## Project Structure

Each project contains:  
- `index.html` → HTML structure  
- `style.css` → Styling and layout  
- `script.js` → JavaScript functionality
