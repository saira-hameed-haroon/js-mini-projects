# 🌤 Weather App

A simple and responsive weather application built using **HTML, CSS, Bootstrap, and JavaScript**.  
Fetches real-time weather data from the **OpenWeatherMap API**.

## Features

- Search weather by **city name**
- Display **temperature**, **humidity**, **wind speed**, and **weather description**
- **Error handling**:
  - Shows message if city not found
  - Prompts user to enter a city if input is empty
- **Responsive design**:
  - Works on desktop and mobile devices
  - Uses Bootstrap for layout and styling
- Minimal and clean **UI with gradient background**
- **Enter key support** for quick search


## Prerequisites (API Key)

To get this app running, you will need an `API key` from OpenWeatherMap:

1. Sign up at OpenWeatherMap.
2. Generate your free API key.
3. Open `script.js` and replace the placeholder text with your `actual API Key`.

## How to Run

1. Download or clone the repository.
2. Open the folder `11-weather-app`.
3. Open `index.html` in your browser.
