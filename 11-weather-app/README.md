# 🌤️ Weather App

A simple and responsive weather application built using **HTML, CSS, Bootstrap, and JavaScript**.  
It fetches real-time weather data using the **OpenWeatherMap API**.

## ✨ Features

- Search weather by **city name**
- Displays **temperature**, **humidity**, **wind speed**, and **weather description**
- **Error handling**:
  - Shows a message if the city is not found  
  - Prompts the user to enter a city if the input is empty
- **Responsive design**:
  - Works on desktop and mobile devices  
  - Uses Bootstrap for layout and styling
- Minimal and clean **UI with a gradient background**
- **Enter key support** for quick search

## 🔑 Prerequisites (API Key)

This project uses the OpenWeatherMap API.  
To run this project locally, you will need your own API key:

1. Sign up at https://openweathermap.org/api  
2. Generate your free API key  
3. Open `script.js` and replace the placeholder text with your **actual API key**

> ℹ️ The live demo uses a demo API key for showcase purposes.  
> For your own usage, always use your own API key.

## ▶️ How to Run

1. Download or clone this repository  
2. Open the folder `11-weather-app`  
3. Open `index.html` in your browser
